# 组件与设计系统

文章模型位于 `shared/article.ts`。每个块保存 `componentId`、字段和稳定 id。模板提供颜色变量，组件把这些数据渲染为内联 HTML。

## 新增组件

在 `shared/packs/` 定义 `ComponentDefinition`，声明字段、默认值、分类与渲染函数，再到 `shared/packs/index.ts` 注册。

字段是纯文本或图片素材 id。使用转义函数处理文本，在组件内部组织样式。不要把文章内容拼接为可执行 HTML。

## 新增设计系统

在 `shared/design.ts` 增加颜色模板，在 `shared/design-system.ts` 声明组件白名单、色板、字号、行高和选择指南。

编辑画布与组件缩略图共用设计系统的版心宽度。图片、字号和文案变化后，检查窄屏的换行效果。

## 体检

`auditCatalog` 渲染默认值、空字段和长字段，核对样式基线、标签平衡与文字完整性。

`auditArticle` 检查当前文章的组件、必填字段、图片和正文链接。它也会提示缺失的收尾元素及连续同类内容块。

体检用于发现结构问题，不能判断著作权授权，也不能替代公众号预览或内容审核。
