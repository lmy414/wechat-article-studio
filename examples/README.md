# 示例数据

本目录中的作品、作者、BV 号和指标均为虚构，只用于演示和测试。图片是项目自绘 SVG，使用 MIT 协议。

- `article.json`：通用文章，可以直接交给 `npm run export`。
- `weekly-issue.json`：周刊公开数据格式。
- `weekly-config.json`：公众号标题、摘要、署名、刊头和阅读原文配置。
- `images/`：与周刊 JSON 中的封面文件名对应的图片。

先启动工作台，再按根目录 README 的周刊命令导入。命令会替换当前文章，并保留版本记录。

真实内容请放在本机目录，勿提交到示例目录。图片可以使用同名 JPEG 或 PNG，导入时会优先选择这两种格式。
